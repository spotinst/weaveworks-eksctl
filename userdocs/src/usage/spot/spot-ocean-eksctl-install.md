# EKSCTL Installation For Ocean

Please approach the latest release in the [releases page](https://github.com/spotinst/weaveworks-eksctl/releases#releases) in our github repo.

Download the EKSCTL version that's compatible with your machine's architecture in the assets list.

Move the downloaded executable of EKSCTL from the Download folder to the bin folder using the following command:`[sudo] mv ~/Downloads/eksctl /usr/local/bin/eksctl`
